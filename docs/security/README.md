# Security Documentation

> Status: **draft / discussion only.**

This application is currently **not** considered secure. The cryptographic
design, threat model, key management, metadata protection, and transport
security are all under development.

This directory will eventually hold:

- A **threat model** describing what the system defends against and what
  it does not.
- A **security audit** of the reference implementation.
- Notes on **key management**, **metadata protection**, and **anonymity
  properties**.
- Documented **known limitations** and the rationale behind them.

Do not use this software for sensitive communication in the meantime.
